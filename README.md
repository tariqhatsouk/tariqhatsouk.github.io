
# Personal Portfolio - Project 04

## Description
A personal portfolio website combining law,
cybersecurity, and web development.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git

## Features
- Responsive navigation
- About Me with profile photo
- Skills grid
- Projects 00-03
- Hobbies
- Contact form
- Light and dark theme switcher

## How to Run
1. Open the project directory.
2. Run: python3 -m http.server 8000
3. Visit: http://localhost:8000/index.html

## Contact Form
The form prepares an email draft.
It does not send messages automatically.
